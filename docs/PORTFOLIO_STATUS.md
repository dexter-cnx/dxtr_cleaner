# Portfolio status metadata

This repository publishes portfolio-facing project metadata in `.portfolio/status_en.json` and `.portfolio/status_th.json`.

Both files follow schema version 1 from `dexter-cnx/portfolio/docs/PROJECT_STATUS_CONTRACT.md`.

Update both locale files when a feature, release, architecture change, or project status materially changes what the public portfolio should show. Keep technical names, versions, URLs, and status values aligned between locales.

These files are public metadata. Never include secrets, credentials, customer data, private URLs, API keys, or tokens.
